Install cloudflared

Cloudflare tunnels require cloudflared, a small open-source connector that creates a secure outbound connection to Cloudflare's edge.

  • Downloads to ~/.local/bin/
  • Verifies integrity before installing
  • Runs as a user service — no root required

Cloudflare API Token

In the Cloudflare dashboard, go to Manage Account → Account API Tokens, then click Create Token.

  1. Add an account policy for Entire Account: Access (Read/Edit), Access: Organizations, Identity Providers, and Groups (Read/Edit), Argo Tunnel (Legacy) (Read/Edit).
  2. Add a domain policy, changing the Entire Account dropdown to All Domains or Specified Domains: DNS (Read/Edit), Zones (Read).
