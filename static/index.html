Install cloudflared

Cloudflare tunnels require cloudflared, a small open-source connector that runs on this machine and creates a secure outbound connection to Cloudflare's edge.

inframatik will:

  • Download cloudflared to ~/.local/bin/
  • Verify its checksum before installing
  • Run it as a user service (no root required)
